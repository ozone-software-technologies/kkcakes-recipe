# This describe about project

#Tech Stack

- Next.js
- Tailwind CSS
- TypeScript
- MongoDB
- Node.js
- Express.js
- Firebase


Project requires login screen
Following Modules has to covered:-
1. Dashboard
2. Ingredients
3. Recipes
4. Inventory
5. Orders
6. Users


Dashboard Module contains following features:-
1. Widgets of today order
2. Widgets of today Inventory


Ingredients Module contains following features:-
1. List of ingredients
2. Add new ingredient
3. Edit ingredient
4. Delete ingredient

Ingredient type are following
1. Processed
2. Raw

In add /edit ingredient there is a field name units which will be combo box and will have following options
1.Grams
2.Pieces
3.Liters
